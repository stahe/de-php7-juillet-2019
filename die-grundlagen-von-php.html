    Anmerkungen

    • Zeile 5: In PHP wird der Typ der Variablen nicht deklariert. Diese haben einen dynamischen Typ, der sich im Laufe der Zeit ändern kann. $nom steht für die Variable mit dem Bezeichner „nom“;
    • Zeile 7: Um etwas auf den Bildschirm auszugeben, kann man die Anweisung print oder die Anweisung „echo“ verwenden;
    • Zeile 9: Mit dem Schlüsselwort array lässt sich ein Array definieren. Die Variable $nom[$i] steht für das Element $i des Arrays $tableau;
    • Zeile 11: Die Funktion count($tableau) gibt die Anzahl der Elemente des Arrays $tableau zurück;
    • Zeilen 13–15: eine Schleife. Da diese nur eine Anweisung enthält, sind die geschweiften Klammern hier optional. Im weiteren Verlauf dieses Dokuments werden wir die geschweiften Klammern systematisch setzen, unabhängig von der Anzahl der Anweisungen;
    • Zeile 14: Zeichenketten werden in Anführungszeichen „“ oder Apostrophe ' gesetzt. Innerhalb von Anführungszeichen werden die Variablen $variable ausgewertet, innerhalb von Apostrophen jedoch nicht;
    • Zeile 17: Mit der Funktion list lassen sich Variablen in einer Liste zusammenfassen und ihnen mit einer einzigen Zuweisungsoperation einen Wert zuweisen. Hier gilt $chaine1="Zeichenkette1" und $chaine2="Zeichenkette2";
    • Zeile 19: Der Operator „.“ ist der Operator zur Verkettung von Zeichenketten;
    • Zeilen 83–86: Das Schlüsselwort function definiert eine Funktion. Ob eine Funktion Werte zurückgibt oder nicht, wird durch die Anweisung return festgelegt. Der aufrufende Code kann die Ergebnisse einer Funktion ignorieren oder abrufen. Eine Funktion kann an beliebiger Stelle im Code definiert werden.
    • Zeile 92: Die vordefinierte Funktion getType($variable) gibt eine Zeichenkette zurück, die den Typ von $variable darstellt. Dieser Typ kann sich im Laufe der Zeit ändern;
    • Zeile 45: Der Operator === vergleicht zwei Elemente streng: Sie müssen denselben Typ haben, um verglichen werden zu können. Der Operator == ist weniger streng: Zwei Elemente können gleich sein, ohne denselben Typ zu haben. Dies zeigen die Anweisungen in den Zeilen 50–60. Im Fall des Operators == erfolgt der Vergleich erst, nachdem beide verglichenen Elemente in denselben Typ umgewandelt wurden. Dabei finden implizite Typumwandlungen statt. Es passiert leicht, dass man diese impliziten Typumwandlungen „vergisst“ und dadurch zu unerwarteten Ergebnissen gelangt, beispielsweise wenn man feststellt, dass eine Bedingung wahr ist, obwohl man erwartet hatte, dass sie falsch ist. Um diese Falle zu vermeiden, verwenden wir systematisch den Vergleichsoperator ===;
    • Zeile 64: Man kann auch die booleschen Operatoren „or“ und „!“ verwenden;
    • Zeile 69: Anstelle der Schreibweise „array()“ kann man die Schreibweise „[]“ verwenden, um ein Array aus „PHP7“ zu initialisieren;
    • Zeile 80: Die vordefinierte Funktion exit beendet die Ausführung des Skripts;
    • Zeile 107: Das Tag ?> markiert das Ende des Skripts PHP. Es ist nicht zwingend erforderlich. Außerdem kann sie im Webkontext Probleme verursachen, wenn ihr Leerzeichen oder Zeilenumbrüche folgen, die schwer zu erkennen sind, da sie in einem Texteditor nicht sichtbar sind. Daher werden wir diesen Tag im weiteren Verlauf des Dokuments systematisch weglassen;

    Hinweis: In diesem Dokument verwenden wir das Schlüsselwort [print], um Text auf der Konsole anzuzeigen. Eine andere Methode, um dasselbe zu erreichen, ist die Verwendung des Schlüsselworts [echo]. Es gibt subtile Unterschiede zwischen diesen beiden Schlüsselwörtern, die im Kontext dieses Dokuments jedoch keine Rolle spielen. Wenn Sie also lieber [echo] verwenden möchten, tun Sie dies bitte.

In der Einarbeitungsphase in die Programmiersprache empfiehlt es sich, möglichst viele der von NetBeans angebotenen Optionen zu überprüfen. Auf diese Weise lernt man viel dazu.     3.5. Typänderungen

    Die Variablen in PHP haben keinen konstanten Typ. Dieser kann sich während der Ausführung je nach dem der Variablen zugewiesenen Wert ändern. Bei Operationen mit Daten verschiedener Typen führt der Interpreter PHP implizite Konvertierungen durch, um die Operanden auf einen gemeinsamen Typ zu bringen. Diese impliziten Konvertierungen können, wenn sie dem Entwickler nicht bekannt sind, eine Quelle für schwer zu findende Fehler sein. Im Folgenden wird ein [bases-04.php]-Skript vorgestellt, das implizite und explizite Konvertierungen veranschaulicht:

    
<?php

// Strenge Typen bei der Parameterübergabe
declare(strict_types=1);

// implizite Typumwandlungen
// Typ --> bool
print "Conversion vers un booléen------------------------------\n";
showBool("abcd", "abcd");
showBool("", "");
showBool("[1, 2, 3]", [1, 2, 3]);
showBool("[]", []);
showBool("NULL", NULL);
showBool("0.0", 0.0);
showBool("0", 0);
showBool("4.6", 4.6);

function showBool(string $prefixe, $var) : void {
  print "(bool) $prefixe : ";
  // Die Konvertierung von $var in einen Booleschen Wert erfolgt automatisch im folgenden Test
  if ($var) {
    print "true";
  } else {
    print "false";
  }
  print "\n";
}

    Kommentare

    • Zeile 4: Fordert eine strenge Typüberprüfung der Funktionsparameter, wenn diese angegeben sind;
    • Zeile 18: Die Funktion [showBool] soll die implizite (automatische) Umwandlung veranschaulichen, die der Interpreter PHP vornimmt, wenn ein Wert beliebigen Typs in einen booleschen Wert umgewandelt werden muss (Zeile 21);
    • Zeile 18: Dem Parameter $var ist kein Typ zugewiesen. Der tatsächliche Parameter kann daher einen beliebigen Typ haben. Der Parameter $prefixe muss hingegen vom Typ „string“ sein. Die Funktion showBool gibt keinen Wert zurück (void);
    • Zeile 21: In der Anweisung if($var) muss der Wert von $var in einen booleschen Wert umgewandelt werden, damit if ausgewertet wird. Erstaunlicherweise liefert der Interpreter PHP für jeden Wert, der ihm übergeben wird, eine Antwort;
    • Zeilen 9–16: Der Wert des Funktionsparameters von [showBool] ist nacheinander:
      • Zeile 9: eine nicht leere Zeichenkette: Ergebnis TRUE (Groß-/Kleinschreibung spielt keine Rolle, TRUE = true);
      • Zeile 10: eine leere Zeichenkette: Ergebnis FALSE;
      • Zeile 11: ein nicht leeres Array: Ergebnis TRUE;
      • Zeile 12: ein leeres Array: Ergebnis FALSE;
      • Zeile 14: die reelle Zahl 0: Ergebnis FALSE;
      • Zeile 15: die ganze Zahl 0: Ergebnis FALSE;
      • Zeile 16: die von 0 verschiedene reelle (oder ganzzahlige) Zahl: Ergebnis TRUE;
