# Einführung in PHP 7: Konsolenskripte und Webdienste

📘 **Zur Kursdokumentation:** [https://stahe.github.io/de-php7-juillet-2019/](https://stahe.github.io/de-php7-juillet-2019/)

---

Dieses Projekt bietet eine Sammlung von Konsolenskripten in PHP 7, die verschiedene Aspekte der Sprache und ihres Ökosystems veranschaulichen.

## Inhalt des Repositorys

Die Beispiele behandeln folgende Themen:
- **Sprachkonstrukte**
- **Dateizugriff**
- **Datenbankzugriff**
- **Internetzugriff**

## Web-Ansatz

Die Webprogrammierung wird hier aus der Perspektive von **Webdiensten** betrachtet. In diesem Zusammenhang definieren wir einen „Webdienst“ als jede Anwendung, die einfachen Text erzeugt (Datenserver), im Gegensatz zu Webseitenservern, die eine Mischung aus HTML, CSS und JavaScript generieren.

### Behandelte Schlüsselkonzepte
Das Projekt untersucht die grundlegenden Webkonzepte, die in der traditionellen Programmierung verwendet werden:
- HTTP-Protokoll
- Antwortformate JSON oder XML
- Sitzungsverwaltung
- Authentifizierung
