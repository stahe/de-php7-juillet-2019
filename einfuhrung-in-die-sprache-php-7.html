    Dieses Dokument ist Teil einer vierteiligen Artikelserie:

    1. [Einführung in die Sprache PHP7 anhand von Beispielen (2019)]. Dies ist das vorliegende Dokument;
    2. [Einführung in die Sprache ECMAScript 6 anhand von Beispielen (2019)];
    3. [Einführung in das VUE.JS-Framework anhand von Beispielen (2019)];
    4. [Einführung in das NUXT.JS-Framework anhand von Beispielen (2019)];

    Es handelt sich dabei ausschließlich um Dokumente für Anfänger. Die Artikel bauen logisch aufeinander auf, sind jedoch nur lose miteinander verbunden:

    • Das Dokument [1] stellt die Sprache PHP 7 vor. Leser, die sich nur für die Sprache PHP interessieren und nicht für die JavaScript-Sprache der folgenden Artikel, können an dieser Stelle aufhören;
    • die Dokumente [2-4] zielen darauf ab, einen JavaScript-Client für den im Dokument [1] entwickelten Steuerberechnungsserver zu erstellen;
    • die JavaScript-Frameworks [vue.js] und [nuxt.js] aus den Artikeln 3 und 4 setzen Kenntnisse des JavaScripts der neuesten Versionen von ECMASCRIPT voraus, nämlich der Version 6. Das Dokument [2] richtet sich daher an diejenigen, die diese JavaScript-Version nicht kennen. Es bezieht sich auf den Steuerberechnungsserver, der im Dokument [1] erstellt wurde. Leser von [2] müssen daher gelegentlich auf das Dokument [1] zurückgreifen;
    • sobald man ECMASCRIPT 6 beherrscht, kann man sich mit dem Framework VUE.JS befassen, das es ermöglicht, JavaScript-Clients zu erstellen, die in einem Browser im SPA-Modus (Single Page Application) ausgeführt werden. Es handelt sich um das Dokument [3]. Es bezieht sich sowohl auf den im Dokument [1] erstellten Steuerberechnungsserver als auch auf den Code des eigenständigen JavaScript-Clients, der in [2] erstellt wurde. Wer sich mit [3] beschäftigt, muss daher gelegentlich auf die Dokumente [1] und [2] zurückgreifen;
    • Sobald man VUE.JS beherrscht, kann man sich mit dem Framework NUXT.JS befassen, das die Erstellung von JavaScript-Clients ermöglicht, die in einem Browser im Modus SSR (Server Side Rendered) ausgeführt werden. Es bezieht sich sowohl auf den im Dokument [1] erstellten Steuerberechnungsserver auf den eigenständigen JavaScript-Client-Code, der in [2] erstellt wurde, sowie auf die Anwendung [vue.js], die im Dokument [3] entwickelt wurde. Der Leser von [4] muss daher gelegentlich auf die Dokumente [1], [2] und [3] zurückgreifen;

    Dieses Dokument enthält eine Liste von Konsolenskripten PHP 7 aus verschiedenen Bereichen (Sprachstrukturen, Zugriff auf Dateien, Datenbanken und das Internet). Die Webprogrammierung wird anhand von Webdiensten behandelt. In diesem Dokument wird als Webdienst jede Webanwendung bezeichnet, die Klartext ausgibt. Es handelt sich dabei um Datenserver und nicht um Webseiten-Server, die eine Mischung aus HTML, CSS und JavaScript darstellen. Es werden klassische Webkonzepte behandelt (Protokoll HTTP, Antworten jSON oder XML, Sitzungsverwaltung, Authentifizierung), die auch in der klassischen Webprogrammierung verwendet werden.

    Heutzutage ist es üblich, Webanwendungen im Client-Server-Modus zu entwickeln:

    • In [1] zeigt der Webbrowser Webseiten für einen Benutzer [5, 7] an. Diese Seiten enthalten JavaScript, das einen Client für einen Webdatendienst [2] sowie einen Client für einen Webseiten-Fragment-Server [3] implementiert. Ein in diesem Bereich etabliertes Framework JS ist Angular 2 von Google (Mai 2019);
    • In [2] ist der Webserver ein Datenserver. Er kann in jeder beliebigen Sprache geschrieben sein. Er erzeugt keine Webseiten im klassischen Sinne (HTML, CSS, JavaScript), außer vielleicht beim ersten Mal. Diese erste Seite kann jedoch von einem klassischen Webserver [3] (kein Datenserver) abgerufen werden. Das JavaScript der Startseite generiert dann die verschiedenen Webseiten der Anwendung, indem es die anzuzeigenden Daten [4] vom Webserver abruft, der als Datenserver [2] fungiert. Er kann außerdem Webseitenfragmente [5] abrufen, um diese Daten auf dem Webseitenserver [3] zu gestalten;
    • in [4] löst der Benutzer eine Aktion aus;
    • in [6,7]: Er erhält Daten, die mit einem Webseitenfragment aufbereitet wurden;

    Hier handelt es sich um eine Client-Server-Anwendung, die in PHP geschrieben wurde. Ein Konsolenskript namens [9] fragt einen Datenserver namens [4] ab. Das hier Gelernte zum Schreiben des Datendienstes lässt sich in einer Webanwendung wiederverwenden.
