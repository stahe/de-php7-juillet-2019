    18. Anwendungsübung – Version 8

    Wir greifen die Beispielanwendung – Version 5 (Absatz „Link“) wieder auf und bauen daraus eine Client-Server-Anwendung auf.

    18.1. Einleitung

    Die Architektur von Version 5 sah wie folgt aus:

    • Die Schicht mit der Bezeichnung [dao] (Data Access Objects) ist für den Datenaustausch mit der Datenbank MySQL und dem lokalen Dateisystem zuständig;
    • die Schicht mit der Bezeichnung [métier] führt die Steuerberechnung durch;
    • Das Hauptskript ist der „Dirigent“: Es instanziiert die Schichten [dao] und [métier] und kommuniziert anschließend mit der Schicht [métier], um die erforderlichen Aufgaben auszuführen;

    Wir werden diese Architektur auf die folgende Client-Server-Architektur umstellen:

    • In [2] werden wir die Schicht [dao] aus Version 5 übernehmen und dabei die Methoden für den Zugriff auf das lokale Dateisystem entfernen. Diese Methoden werden in die Schicht [dao] des Clients [6, 7] migriert;
    • in [3], die Schicht [métier] bleibt die der Version 5 ohne ihre Methoden [executeBatchImpôts, saveResults], die in die Schicht [dao] und [7] des Clients migriert werden;
    • In [4] muss das Serverskript geschrieben werden: Es muss:
      • die Schichten [métier], [dao] und [3, 2] erstellen;
      • mit dem Client-Skript [5, 7] zu kommunizieren;
    • In [7] muss die Client-Schicht [dao] geschrieben werden:
      • Sie wird ein Client HTTP des Server-Skripts [4, 5] sein;
      • sie übernimmt die Methoden für den Zugriff auf das lokale Dateisystem der Schicht [dao] aus Version 5;
    • In [8] wird die Client-Schicht [métier] die Schnittstelle [InterfaceMetier] der Version 5 einhalten. Ihre Implementierung wird jedoch anders sein. In Version 5 führte die Schicht [métier] die Steuerberechnung durch. Hier übernimmt die Serverschicht [métier] diese Berechnung. Die Schicht [métier] wird daher die Schichten [dao] und [7] aufrufen, um mit dem Server zu kommunizieren und ihn aufzufordern, die Steuer zu berechnen;
    • in [9] muss das Konsolenskript die Client-Schichten [dao, métier] instanziieren und deren Ausführung starten;

<?php

// Namensraum
namespace Application;

// Definition einer Klasse ImpotsWithDataInDatabase
class ServerDao implements InterfaceServerDao {
  // das Objekt vom Typ TaxAdminData, das die Daten der Steuerklassen enthält
  private $taxAdminData;
  // das Objekt vom Typ [Database], das die Merkmale von BD enthält
  private $database;

  // Hersteller
  public function __construct(string $databaseFilename) {
    // die Konfiguration JSON wird in der Datenbank gespeichert
    $this->database = (new Database())->setFromJsonFile($databaseFilename);
    // Das Attribut wird vorbereitet
    $this->taxAdminData = new TaxAdminData();
    try {
      // Die Verbindung zur Datenbank wird geöffnet
      $connexion = new \PDO($this->database->getDsn(), $this->database->getId(), $this->database->getPwd());
      // Es soll bei jedem Fehler von SGBD eine Ausnahme ausgelöst werden
      $connexion->setAttribute(\PDO::ATTR_ERRMODE, \PDO::ERRMODE_EXCEPTION);
      // Eine Transaktion wird gestartet
      $connexion->beginTransaction();
      // Die Tabelle der Steuerklassen wird gefüllt
      $this->getTranches($connexion);
      // Die Konstantentabelle wird gefüllt
      $this->getConstantes($connexion);
      // Die Transaktion wird bei Erfolg beendet
      $connexion->commit();
    } catch (\PDOException $ex) {
      // Ist eine Transaktion im Gange?
      if (isset($connexion) && $connexion->inTransaction()) {
        // Die Transaktion wird bei einem Fehler beendet
        $connexion->rollBack();
      }
      // Die Ausnahme wird an den aufrufenden Code weitergeleitet
      throw new ExceptionImpots($ex->getMessage());
    } finally {
      // Die Verbindung wird geschlossen
      $connexion = NULL;
    }
  }

  // Daten aus der Datenbank lesen
  private function getTranches($connexion): void {
    …
  }

  // Auslesen der Konstantentabelle
  private function getConstantes($connexion): void {
    …
  }

  // gibt die Daten zurück, die zur Berechnung der Steuer benötigt werden
  public function getTaxAdminData(): TaxAdminData {
    return $this->taxAdminData;
  }

}

    Das Skript [impots-server] implementiert die Schicht [web] wie folgt:

    
<?php

// Strikte Einhaltung der deklarierten Typen der Funktionsparameter
declare (strict_types=1);

// Namensraum
namespace Application;

// Fehlerbehandlung durch PHP
//ini_set("display_errors", "0");
//
// Pfad zur Konfigurationsdatei
define("CONFIG_FILENAME", "Data/config-server.json");

// die Konfiguration wird abgerufen
$config = \json_decode(file_get_contents(CONFIG_FILENAME), true);

// die für das Skript erforderlichen Abhängigkeiten werden eingebunden
$rootDirectory = $config["rootDirectory"];
foreach ($config["relativeDependencies"] as $dependency) {
  require "$rootDirectory$dependency";
}
// Absolute Abhängigkeiten (Bibliotheken von Drittanbietern)
foreach ($config["absoluteDependencies"] as $dependency) {
  require "$dependency";
}

// Definition der Konstanten
define("DATABASE_CONFIG_FILENAME", $config["databaseFilename"]);
//
// Symfony-Abhängigkeiten
use \Symfony\Component\HttpFoundation\Response;
use \Symfony\Component\HttpFoundation\Request;

// Vorbereitung der Antwort JSON vom Server
$response = new Response();
$response->headers->set("content-type", "application/json");
$response->setCharset("utf-8");

// die aktuelle Anfrage wird abgerufen
$request = Request::createFromGlobals();
// Authentifizierung
$requestUser = $request->headers->get('php-auth-user');
$requestPassword = $request->headers->get('php-auth-pw');
// Existiert der Benutzer?
$users = $config["users"];
$i = 0;
$trouvé = FALSE;
while (!$trouvé && $i < count($users)) {
  $trouvé = ($requestUser === $users[$i]["login"] && $users[$i]["passwd"] === $requestPassword);
  $i++;
}
// Festlegen des Statuscodes der Antwort
if (!$trouvé) {
  // Nicht gefunden – Code 401
  $response->setStatusCode(Response::HTTP_UNAUTHORIZED);
  $response->headers->add(["WWW-Authenticate" => "Basic realm=" . utf8_decode("\"Serveur de calcul d'impôts\"")]);
  // Fehlermeldung
  $response->setContent(\json_encode(["réponse" => ["erreur" => "Echec de l'authentification [$requestUser, $requestPassword]"]], JSON_UNESCAPED_UNICODE));
  $response->send();
  // Ende
  exit;
}
// Es liegt ein gültiger Benutzer vor – die empfangenen Parameter werden überprüft
$erreurs = [];
// Es müssen drei Parameter vorhanden sein: GET
$method = strtolower($request->getMethod());
$erreur = $method !== "get" || $request->query->count() != 3;
// Fehler?
if ($erreur) {
  $erreurs[] = "Méthode GET requise avec les seuls paramètres [marié, enfants, salaire]";
}

// Der Familienstand wird abgerufen
if (!$request->query->has("marié")) {
  $erreurs[] = "paramètre marié manquant";
} else {
  $marié = trim(strtolower($request->query->get("marié")));
  $erreur = $marié !== "oui" && $marié !== "non";
  // Fehler?
  if ($erreur) {
    $erreurs[] = "paramètre marié [$marié] invalide";
  }
}

// Die Anzahl der Kinder wird abgerufen
if (!$request->query->has("enfants")) {
  $erreurs[] = "paramètre enfants manquant";
} else {
  $enfants = trim($request->query->get("enfants"));
  // Die Anzahl der Kinder muss eine ganze Zahl >= 0 sein
  $erreur = !preg_match("/^\d+$/", $enfants);
  // Fehler?
  if ($erreur) {
    $erreurs[] = "paramètre enfants [$enfants] invalide";
  }
}

// Das Jahresgehalt wird abgerufen
if (!$request->query->has("salaire")) {
  $erreurs[] = "paramètre salaire manquant";
} else {
  // Das Gehalt muss eine ganze Zahl >= 0 sein
  $salaire = trim($request->query->get("salaire"));
  $erreur = !preg_match("/^\d+$/", $salaire);
  // Fehler?
  if ($erreur) {
    $erreurs[] = "paramètre salaire [$salaire] invalide";
  }
}

// Weitere Parameter in der Abfrage?
foreach (\array_keys($request->query->all()) as $key) {
  // Gültiger Parameter?
  if (!\in_array($key, ["marié", "enfants", "salaire"])) {
    $erreurs[] = "paramètre [$key] invalide";}
}

// Fehler?
if ($erreurs) {
  // Es wird ein Fehlercode 400 an den Client gesendet
  $response->setStatusCode(Response::HTTP_BAD_REQUEST);
  $response->setContent(json_encode(["réponse" => ["erreurs" => $erreurs]], JSON_UNESCAPED_UNICODE));
  $response->send();
  exit;
}
// Es ist alles vorhanden, was zum Arbeiten benötigt wird
// Erstellung der Serverarchitektur
$msgErreur = "";
try {
  // Erstellung der Schicht [dao]
  $dao = new ServerDao($config["databaseFilename"]);
  // Erstellung der Schicht [métier]
  $métier = new ServerMetier($dao);
} catch (ExceptionImpots $ex) {
// Fehler wird vermerkt
  $msgErreur = utf8_encode($ex->getMessage());
}
// Fehler?
if ($msgErreur) {
  // Es wird ein Fehlercode 500 an den Client gesendet
  $response->setStatusCode(Response::HTTP_INTERNAL_SERVER_ERROR);
  $response->setContent(\json_encode(["réponse" => ["erreur" => $msgErreur]], JSON_UNESCAPED_UNICODE));
  $response->send();
  exit;
}
// Steuerberechnung
$result = $métier->calculerImpot($marié, (int) $enfants, (int) $salaire);
// Die Antwort wird zurückgegeben
$response->setContent(json_encode(["réponse" => $result], JSON_UNESCAPED_UNICODE));
$response->send();

    • Zeile 12: Die Funktion [calculerImpots] berechnet die Steuer eines Steuerpflichtigen;
    • Zeile 15: Die Funktion [saveResults] speichert die Daten der Tabelle [$taxPayersData], die die Ergebnisse mehrerer Steuerberechnungen enthalten, in der Datei [$resultsFilename];

    Die Schnittstelle [InterfaceClientDao] wird durch die folgende Klasse [ClientDao] implementiert:

    
<?php

namespace Application;

// Abhängigkeiten
use \Symfony\Component\HttpClient\HttpClient;

class ClientDao implements InterfaceClientDao {
  // Verwendung eines Traits
  use TraitDao;
  // Attribute
  private $urlServer;
  private $user;

  // Konstruktor
  public function __construct(string $urlServer, array $user) {
    $this->urlServer = $urlServer;
    $this->user = $user;
  }

  // Steuerberechnung
  public function calculerImpot(string $marié, int $enfants, int $salaire): array {
    // Ein Kunde wird angelegt HTTP
    $httpClient = HttpClient::create([
        'auth_basic' => [$this->user["login"], $this->user["passwd"]],
        "verify_peer" => false
    ]);
    // Anfrage an den Server
    $response = $httpClient->request('GET', $this->urlServer,
      ["query" => [
          "marié" => $marié,
          "enfants" => $enfants,
          "salaire" => $salaire
    ]]);
    // die Antwort wird abgerufen
    $json = $response->getContent(false);
    $array = \json_decode($json, true);
    $réponse = $array["réponse"];
    // Protokolle
    // print "$json=json\n";
    // Der Status der Antwort wird abgerufen
    $statusCode = $response->getStatusCode();
    // Fehler?
    if ($statusCode !== 200) {
      // Es liegt ein Fehler vor – es wird eine Ausnahme ausgelöst
      $réponse = ["statut HTTP" => $statusCode] + $réponse;
      $message = \json_encode($réponse, JSON_UNESCAPED_UNICODE);
      throw new ExceptionImpots($message);
    }
    // Die Antwort wird zurückgegeben
    return $réponse;
  }

}

    Anmerkungen

    • Zeile 10: Es wird [TraitDao] eingefügt (siehe Abschnitt „Link“), das die Methoden [getTaxPayersData] und [saveResults] implementiert. Es bleibt also nur noch die Methode [calculerImpots] zu implementieren. Diese ist in den Zeilen 22–49 implementiert;
    • Zeilen 16–19: Der Konstruktor der Klasse [ClientDao] erhält zwei Parameter:
      • den URL [$urlServer] des Steuerberechnungsservers;
      • das Array [$user] mit den Schlüsseln „login“ und „passwd“, das den Benutzer definiert, der die Anfrage stellt;
    • Zeile 22: Die Methode [calculerImpots] empfängt die drei Parameter, die an den Steuerberechnungsserver gesendet werden sollen;
    • Zeilen 24–27: Es wird ein Client HTTP erstellt mit:
      • Zeile 25: die Anmeldedaten des Benutzers, der die Anfrage stellt;
      • Zeile 26: die Option, die bewirkt, dass der Client HTTP die Gültigkeit des vom Server gesendeten Zertifikats SSL nicht überprüft;
    • Zeilen 29–34: Der Server wird mit den drei erwarteten Parametern abgefragt;
    • Zeile 36: Die Antwort jSON vom Server wird abgerufen. Wenn der Parameter [false] nicht an die Methode [Response::getContent] übergeben wird, löst das Objekt [Response] eine Ausnahme aus, sobald versucht wird, den Inhalt der Antwort [Response::getContent] abzurufen, sofern der Status der Serverantwort im Bereich [3xx-5xx] liegt (Fehlerfall), löst das Objekt [Response] eine Ausnahme aus, sobald versucht wird, den Inhalt der Antwort [Response::getContent] oder deren Header HTTP und [Response::getHeaders] abzurufen. Unabhängig vom Status HTTP der Antwort soll hier Zugriff auf deren Inhalt möglich sein, und sei es nur, um ihn zu protokollieren (Zeile 40);
    • Zeilen 37–38: Die Antwort des Servers ist die Zeichenkette jSON aus einem Array [‘réponse’=>qqChose]. Wir extrahieren den Wert [qqChose];
    • Zeile 40: Die Antwort „jSON“ wird im Entwicklungsmodus protokolliert;
    • Zeile 42: Der Statuscode der Antwort wird abgerufen;
    • Zeilen 44–49: Ist der Statuscode HTTP nicht 200, ist auf unserem Server ein Problem aufgetreten. In diesem Fall wird eine Ausnahme vom Typ [ExceptionImpots] ausgelöst, deren Meldung die Antwort jSON des Servers ist, ergänzt um den Code HTTP der Antwort;
    • Zeile 51: Es wird das Ergebnis zurückgegeben, bei dem es sich um ein assoziatives Array mit den Schlüsseln [impôt, surcôte, décôte, réduction, taux] handelt;

    Die Schicht [métier] [8] implementiert die folgende Schnittstelle [InterfaceClientMetier]:

    
<?php

// Namensraum
namespace Application;

interface InterfaceClientMetier {

  // Steuerberechnung für einen Steuerpflichtigen
  public function calculerImpot(string $marié, int $enfants, int $salaire): array;

  // Steuerberechnung im Batch-Modus
  public function executeBatchImpots(string $taxPayersFileName, string $resultsFileName, string $errorsFileName): void;

    • Zeile 9: Die Funktion [calculerImpots] berechnet die Steuer;
    • Zeile 12: Die Funktion [executeBatchImpots] berechnet die Steuer für die Steuerzahler, deren Daten in der Datei [$taxPayersFileName] enthalten sind, speichert die Ergebnisse in der Datei [$resultsFileName] und die aufgetretenen Fehler in der Datei [$errorsFileName];

    Die Schnittstelle [InterfaceClientMetier] wird durch die folgende Klasse [ClientMetier] implementiert:

    
<?php

// Namensraum
namespace Application;

class ClientMetier implements InterfaceClientMetier {
  // Attribut
  private $clientDao;

  // Konstruktor
  public function __construct(InterfaceClientDao $clientDao) {
    // Die Referenz wird auf der Ebene [dao] gespeichert
    $this->clientDao = $clientDao;
  }
  
  // Steuerberechnung
  public function calculerImpot(string $marié, int $enfants, int $salaire): array {
    return $this->clientDao->calculerImpot($marié, $enfants, $salaire);
  }

  // Steuerberechnung im Batch-Modus
  public function executeBatchImpots(string $taxPayersFileName, string $resultsFileName, string $errorsFileName): void {
    // Ausnahmen, die aus der Ebene [dao] stammen, werden weitergeleitet
    // Steuerpflichtige Daten werden abgerufen
    $taxPayersData = $this->clientDao->getTaxPayersData($taxPayersFileName, $errorsFileName);
    // Ergebnistabelle
    $results = [];
    // Auswertung der Ergebnisse
    foreach ($taxPayersData as $taxPayerData) {
      // Die Steuer wird berechnet
      $result = $this->calculerImpot(
        $taxPayerData->getMarié(),
        $taxPayerData->getEnfants(),
        $taxPayerData->getSalaire());
      // Ergänzung von [$taxPayerData]
      $taxPayerData->setFromArrayOfAttributes($result);
      // das Ergebnis wird in die Ergebnistabelle eingetragen
      $results [] = $taxPayerData;
    }
    // Speichern der Ergebnisse
    $this->clientDao->saveResults($resultsFileName, $results);
  }

}
